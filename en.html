Quick start

  1. Download: get the latest installer above
  2. Install: run the installer and follow the prompts
  3. Launch: run SnapPost and the interface opens in your browser
  4. Sign up: create an account (enter a referral code if you have one) and the trial starts automatically
  5. Add an account: add your Facebook account and log in to the Page
  6. Upload content: text files (.txt) and images (.png / .jpg)
  7. Start sending: choose the target Page, set the options and press start
Make sure your Facebook account is in good standing before use. Very frequent bulk sending can trigger Facebook security checks, so set a reasonable interval.

System requirements
